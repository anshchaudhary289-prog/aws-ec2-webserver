# AWS EC2 Web Server Deployment

Deployed a web server on AWS EC2 using Linux and Apache.

## What I did
- Launched an EC2 t2.micro Linux instance on AWS Academy
- Connected via SSH
- Installed Apache web server
- Configured Security Groups for HTTP (port 80) and SSH (port 22)
- Deployed a basic web page on the server

## Tech Stack
- AWS EC2
- Amazon Linux
- Apache HTTP Server
- Security Groups
- SSH

## Key Concepts Learned
- EC2 instance types and configuration
- Security Group rules (inbound/outbound)
- Linux basic commands
- Web server setup on cloud
